# 左侧目标叶 · 单条闭合轮廓与遮盖记账

本目录给出针对**左侧那片叶**的一条可直接采用的闭合轮廓，并把"实见叶面积"与
"为跨过纸带遮盖而推断的部分"分开计量。所有处理只针对这一片叶；同一张纸上的
其他叶不受这笔遮盖影响。

## 1. 场景与判断依据

在已校正的馆藏平面（620 × 472 px ＝ 320 × 240 mm）上，左侧目标叶的情况：

- 一条竖向装裱纸带压住叶片一侧叶缘，纸带另一侧露出一小段**带真实叶齿的尖**。
- 该外露尖与叶片主身的 PCA 主轴**严格共线**（拟合轴角 32.87°，夹具真值 32°，
  外露尖到轴线的垂直距离 ≈ 0），且位于主轴越过纸带的延长端 → 判为**同一叶片
  的叶尖**，纳入轮廓。
- 旁边一片**同色碎叶**压在上方，其窄带朝纸带方向伸出但与目标叶之间留有真实
  间隙（窄带末端距纸带边缘约 7 px，与目标叶不连通），且明显偏离主轴 → 判为
  **独立碎叶，排除在轮廓外**。
- 纸带是唯一允许引入"推断"边界/面积的地方。

判断只使用渲染图像证据 + 用户圈定的三个标记区（主身、被盖段、碎叶确认边），
不读取任何真值掩膜；真值仅用于最后的独立审计。

## 2. 处理流程（scripts/build_contour.py）

1. Lab 色度稳健分割叶组织，得到连通组件。
2. 在"被盖段"标记内检测暖色、低彩度的纸带条带，并沿纸带切断组织，恢复被纸带
   隔开的主身与叶尖两个可见组件（半透明纸带会透出叶色形成细桥，必须先切断）。
3. 用主身组件拟合 PCA 主轴与平滑半宽包络；按"越带、轴向在前、近轴、面积更小"
   把外露齿尖判回本叶，把碎叶组件排除。
4. 推断桥 = 平滑包络落在纸带内、且无实见组织的部分，加 1 px 连接边带保证与
   主身、叶尖 8-连通，合并为单一连通叶片后提取一条外轮廓。
5. 轮廓点按"是否邻接推断桥"分为 observed / inferred；齿尖感知地选取 40 个顶点，
   并强制纳入实见↔推断的过渡点，输出一条闭合多边形。

## 3. 交付的轮廓（output/region_card.json）

- 单一闭合、无自交的多边形，**40 个顶点**（达到馆藏卡区域上限），归一化 0–1
  坐标，`purpose=inspection`，已通过 LeafLedger `geometry.validate_polygon`。
- 36 条 observed 边（保留实际露出的叶齿）＋ 4 条 inferred 边（顶点 1 基编号
  20、21、29、30，即纸带上的平滑桥接段）。
- 在 Geometry 中把这些顶点作为一个采样区域，再用 area 模式测量即可。

## 4. 面积（与应用 Geometry 口径一致）

栅格化采用与 `geometry.polygon_mask()` 相同的 PIL 例程，因此像素数与应用
Geometry 标签逐像素一致（26,322 px）。

| 量 | px | mm² |
|---|---:|---:|
| 实见 observed（外露叶身＋外露齿尖） | 24,246 | **6,367.020** |
| 推断 inferred（纸带内平滑桥，仅本轮廓） | 2,076 | **540.886** |
| 合计 raster（单片叶） | 26,322 | **6,907.906** |

- `observed + inferred = raster` 严格成立（误差 < 0.002 mm²）。
- 推断占比 **7.83%**，且推断像素 94.4% 落在真实纸带内，其余为 1 px 连接边带，
  无一处越出纸带邻域。
- 矢量（鞋带）面积 6,850.154 mm²，与栅格面积相差约 0.8%。

### 关于 40 顶点预算的已知偏差（已量化，非碎叶污染）

密齿叶缘在固定 40 顶点下，相邻齿尖之间由直线弦连接，多边形趋近凸包：

- 交付卡片对真实目标叶的 Dice ＝ **0.943**；像素级精细掩膜（含全部齿）的
  Dice ＝ **0.990**。
- 卡片比真实叶多出的像素占 8.73%，全部是齿尖之间的弦内区域；
  **碎叶泄漏 0 px、其他叶泄漏 0 px**（审计确认）。
- 若需要更贴近齿的面积，应以 `raster_area_mm2`（像素级）为准；卡片多边形面积
  受馆藏卡 40 顶点上限约束，无法完全消除该弦偏差。

## 5. 遮盖只计这一次（output/occlusion_ledger.json）

`occlusion_ledger.json` 的 `scope=left_target_leaf_only`，
`applies_to_other_leaves_on_sheet=false`。推断区被限定在该轮廓的纸带桥，同纸
上其他叶的测量不会继承这笔遮盖，也不会出现全局排除区。

## 6. 输出文件

- `region_card.json` — 可直接录入的单条闭合区域（顶点）。
- `occlusion_ledger.json` — 仅属于本轮廓的遮盖记账与推断边编号。
- `contour_result.json` — 完整数值结果（顶点、边类别、两套面积、纸带 bbox 等）。
- `contour_overlay.png` — 图上可辨：绿边＝实见（含齿），橙边＋斜线＝纸带上的
  推断桥，红框＝被排除的同色碎叶。
- `audit.json` — 对真值掩膜的独立审计（碎叶/其他叶零泄漏、叶尖找回率等）。
- `app_validation.json` — 用 LeafLedger 自身 Geometry 代码复算的结果。

## 7. 复现

```bash
python3 -P scripts/make_fixture.py        # 合成校正馆藏图与真值（无照片时的夹具）
python3 -P scripts/build_contour.py       # 分割、归属、单轮廓与面积拆分
python3 -P scripts/emit_deliverables.py   # 生成 region_card / occlusion_ledger
PYTHONPATH=/workspace:/opt/pointwise-env/site-packages \
  python3 -P scripts/validate_with_app.py # 用应用 Geometry 代码验收
```

`-P` 让 Python 不把脚本目录/当前目录加入 `sys.path`，避免数据目录中的同名模块
被导入，同时保留可信环境里的 numpy / scipy / Pillow / OpenCV。
